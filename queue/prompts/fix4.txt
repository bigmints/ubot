## Problem
The LLM sometimes ignores the system prompt and says things like "I'll get back to you" without actually scheduling a follow-up. This middleware acts as a safety net.

## Implementation

Add a function called `detectVaguePromises(text: string): boolean` that scans response text for these banned phrases (case-insensitive):
- "get back to you"
- "follow up" (but NOT in the context of "schedule follow-up" or "follow-up tool")
- "let you know"
- "update you"
- "check and let you know"
- "circle back"
- "come back to you"

Then add a function called `checkForScheduledFollowup(toolCalls: any[]): boolean` that checks if any tool call in this turn was `schedule_followup`.

In the `handleIncomingMessage` function, AFTER the orchestrator returns its response but BEFORE sending it back to the user, add this check:

```typescript
// Promise tracker: if LLM made a vague promise but didn't schedule a follow-up, auto-schedule one
const hasPromise = detectVaguePromises(response.content || '');
const hasScheduledFollowup = checkForScheduledFollowup(response.toolCalls || []);

if (hasPromise && !hasScheduledFollowup) {
  // Auto-schedule a follow-up
  const followUpStore = ctx.getFollowUpStore?.();
  if (followUpStore) {
    const now = new Date();
    const followUpAt = new Date(now.getTime() + 60 * 60 * 1000); // 1 hour from now

    // Get conversation history for context
    const convStore = ctx.orchestrator.getConversationStore?.();
    let context = 'Conversation context not available';
    if (convStore) {
      const history = await convStore.getHistory(sessionId, 10);
      context = history.slice(-5).map(m => `${m.role}: ${m.content?.slice(0, 200)}`).join('\n');
    }

    await followUpStore.create({
      sessionId,
      contactId: msg.senderId,
      channel: msg.channel,
      reason: 'LLM made a vague promise to follow up — auto-scheduled',
      context: context.slice(0, 1000),
      priority: 'normal',
      followUpAt,
      maxAttempts: 2,
    });

    console.log(`[PromiseTracker] Detected vague promise in response, auto-scheduled follow-up for ${msg.senderId} in 1 hour`);

    // Optionally append a note to the response so the user knows something is being tracked
    // response.content += '\n\n(Note: I have scheduled a follow-up to address this.)';
  }
}
```
