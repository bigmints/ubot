Install Youbot

Your concierge. Your computer. Your choice of AI.

The installer keeps Youbot inside your user account. It does not use sudo or weaken your computer’s security settings.

Before you start

  • A current 64-bit Mac or Linux computer, or a 64-bit Windows computer for the launcher.
  • Internet access and enough free space to build the app.
  • An AI provider API key, or Ollama with a tool-capable model. A chat subscription may not include API credit.

Choose your setup

On a Mac

Terminal
curl --proto '=https' --tlsv1.2 -fsS https://youbot.live/install.sh -o install.sh
less install.sh
bash install.sh

  1. Download and review

    Open Terminal, paste the commands above, and press q when you finish reviewing the installer.

  2. Install in your account

    The final command downloads any missing private Node.js runtime, builds Youbot, and installs it without administrator access.

  3. Start Youbot

    Run ~/.local/bin/youbot start, then open localhost:11490.

On Linux

Terminal
curl --proto '=https' --tlsv1.2 -fsS https://youbot.live/install.sh -o install.sh
less install.sh
bash install.sh

  1. Download and review

    Open a terminal, paste the commands above, and press q when you finish reviewing the installer.

  2. Install in your account

    The final command downloads any missing private Node.js runtime, builds Youbot, and installs it without root access.

  3. Start Youbot

    Run ~/.local/bin/youbot start, then open localhost:11490.

On Windows

  1. Download and extract

    Download the project from GitHub, then choose Extract All. A shell installer for Windows is not available.

  2. Open the launcher

    Open Start Youbot.cmd in the extracted folder, not inside the ZIP.

  3. Follow guided setup

    Create your local login, wait for setup, then open Youbot and connect your AI provider.

Starting and stopping

Use youbot start, youbot stop, youbot status and youbot logs. If your shell cannot find youbot, add ~/.local/bin to your PATH.

The installer resolves the selected source version to one immutable Git commit before downloading it. Review install.sh whenever you want. If device policy blocks setup, ask your administrator; do not disable operating-system protections.

A managed setup is planned for a future release. Self-hosted Youbot needs your computer to stay awake and running.
