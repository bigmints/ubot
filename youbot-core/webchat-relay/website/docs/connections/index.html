Configure

Connect your channels

Meet people where they already are.

Connect only the channels you intend your concierge to use. Availability depends on the integration, your account and the services running on your computer.

Web chat

The web relay gives your installation a visitor link. Your local Youbot connects outward to pick up messages and send replies. Share the generated visitor URL from your dashboard.

WhatsApp

Open the WhatsApp connection screen and scan its QR code using the linked-device flow on your phone. Review the connection state and test a visitor message before relying on replies.

Telegram

Create a bot through Telegram’s BotFather, then enter the bot token in Youbot’s Telegram connection settings. Keep the token private and test the bot from Telegram.

iMessage

iMessage uses a separately running BlueBubbles server. Configure its server URL and password in Youbot. This connection depends on the BlueBubbles host remaining available.

Other services

The project also supports integrations, scheduled tasks and MCP tools. Review the permissions each connection grants, and start with the minimum your concierge needs. A connected service does not mean every action should run without approval.
