Configure

Your visitor link

One link. A more personal hello.

During setup, choose a simple public address such as https://youbot.live/your-name. Youbot checks it live and reserves it for this installation. Letters, numbers, and single hyphens are supported.

Choose the address

Open Help & setup or Website chat, enter the name you want, and wait for the available confirmation before reserving it. Some names are kept for Youbot pages and cannot be selected. Each installation keeps one relay address so links shared with visitors remain stable.

Share the public link

Copy the relay link from Website chat and send it to visitors, add it to a profile, or use the provided website widget. Youbot keeps the signed tenant link working internally as a fallback, so existing generated links continue to open.

Keep owner access private

The public relay address is meant to be shared. Bot credentials, owner links, local sign-in details, and API keys are private. Do not place private credentials in a website or public message.

Use it away from home

The public link opens from phones and other computers. Visitors do not install Youbot. Your own Youbot installation still needs to be running and connected before it can answer.

When your computer is offline

The relay can accept a visitor request while the runtime is reachable. If Youbot is stopped, asleep, or disconnected, the concierge cannot produce a reply. The managed relay stores configuration and conversation history in Firestore, while queued message records expire automatically. Treat local backups and retention as separate owner responsibilities.
