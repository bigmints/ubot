Troubleshooting

Let’s get your concierge back on track.

Setup could not finish

Check your internet connection and free disk space, then choose Try setup again. Native dependency errors may require developer tools. Desktop setup diagnostics are in ~/.youbot-desktop/setup.log; review private information before sharing an excerpt.

Another Youbot is already running

Stop that installation first, then retry. The launcher deliberately does not stop an unrelated process just to free a port.

No AI reply

Confirm that Youbot is running and the computer is awake. Check the channel connection, then your AI model, API key and available provider credit. For local AI, confirm that Ollama is running and the chosen model is installed.

The visitor link does not open

Use the exact generated URL. Check the relay deployment, DNS and HTTPS configuration. A website that loads successfully does not, by itself, prove that your concierge is connected.

A reply disappeared after refreshing

Reopen the conversation. The app checks a pending request rather than immediately resending it. Avoid repeated submissions while a response is still processing.

Forgotten local login

Desktop login configuration is in ~/.youbot-desktop/config.json. Get trusted help recovering it and never post the full file publicly.

Need more help?

Check the project repository with your repository access. Include the setup method, operating system, what happened and a short redacted error. Never include credentials or private conversations.
